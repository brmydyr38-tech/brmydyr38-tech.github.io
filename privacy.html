Privacy Policy

Last updated: October 12, 2026

AutoTube is a private tool used only by the owner of the YouTube channel Tiny Giant Steps to publish that channel's own videos. It is not offered to the public and has no other users.

What data it accesses

With the channel owner's permission (Google OAuth), AutoTube uses the YouTube Data API and YouTube Analytics API to: upload videos to the owner's channel, read the channel's own video list and processing status, and read the channel's own analytics (views, watch time, subscribers). It does not read, collect or store data about viewers or any other users.

How data is stored

Access tokens are stored only as encrypted secrets in the owner's private repository and on the owner's computer. Channel statistics are stored in the owner's private repository. Nothing is sold, shared or transferred to third parties.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. AutoTube's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube is subject to the YouTube Terms of Service and Google Privacy Policy.
